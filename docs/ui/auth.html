かんたん登録は、あとからID・パスワードやGoogleに切り替えられます。Lvと書き込み履歴は引き継ぎます。

■ Lv（PHOEBE）とは

書き込みの信頼度です。書き込みを続けると上がります。板やスレによっては、一定のLv以上でないと書き込めません。名前欄の識別子の末尾に出ます。

■ 専ブラをお使いの方

登録後にアカウント設定で「専ブラ用認証キー」を発行し、専ブラで最初に書き込むときメール欄に!#キーを入れてください。
