認証・登録

書き込みには認証・登録が必要です。認証が終わると 雑談掲示板 に戻ります。

新しく登録するログイン

  1. 登録方法を選ぶ

  2. 利用規約と投稿の責任

    投稿の内容に関する責任は投稿者にあります。他人の権利を侵害する投稿、法令に違反する投稿をしてはいけません。
    削除・規制の判断のため、投稿時の接続情報（IP アドレス・回線・端末情報）を記録します。法令に基づく開示請求に応じる場合があります。
    （利用規約の全文。第 2 版 2026-11-xx）

  3. 認証の前にお読みください

    推奨環境: Safari・Google Chrome・Microsoft Edge・Mozilla Firefox の最新版。これら以外では認証できないことがあります。
    認証できないことがある例
    1. 専用ブラウザ（専ブラ）の内蔵ブラウザ → このページの URL を推奨ブラウザで開き直してください。
    2. 一部のアプリ内ブラウザ（X・LINE・Discord など）→「ブラウザで開く」などで推奨ブラウザへ移ってください。
    3. 「PC 版サイトを見る」「デスクトップ表示」がオン → オフにして再読み込みしてください。
    4. ユーザーエージェントを変更する拡張機能・アプリの設定 → 切ってから再読み込みしてください。

  4. 人間であることの確認

    Turnstile のウィジェット
    （Cloudflare が表示する確認欄）

登録すると、この端末に認証情報（Cookie）が保存されます。2 回目からは認証は不要です。

かんたん登録は、あとから ID・パスワードや Google に切り替えられます。Lv と書き込み履歴は引き継ぎます。

■ Lv（PHOEBE）とは

書き込みの信頼度です。書き込みを続けると上がります。板やスレによっては、一定の Lv 以上でないと書き込めません。名前欄の識別子の末尾に表示されます。

■ 専ブラをお使いの方

登録後、アカウント設定で「専ブラ用認証キー」を発行し、専ブラの初回の書き込みでメール欄に !#キー を入れてください。
