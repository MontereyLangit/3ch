## 概要

- 要は認証済ユーザーのLv制機能＝投稿者の信頼性を測る。
- Lv0～10まであり、Lvに応じて様々な制限・規制がかかる。また、識別IDの後半部分先頭に0~9,\*で表示(10は\*で表示)。
- 未認証ユーザーはL0～L2まで(上がりづらくする)。Google OAuthは(複垢量産が難しく、間違いなく信頼できるので)10固定。
  - L0～L1 -> 23h, L1～L2 -> 23^2h 23にLv+1を掛ける
- その他のユーザーについては、3~9(仮ID: 上がりにくい, ID/PASS: すぐ上がる)で、指定した条件(ISP(ASN)、地域、端末情報、UA等)に当てはまる場合L0～9。
  - ID/PASS: L3～4 -> 23h, 4～5 -> 23 \* 2h, 5～6 -> 23 \* 3h ... 23にLv - 2を掛ける / 仮ID: L3～4 -> 23h, 4～5 -> 23 \* 2h, 5～6 -> 23 \* 2^2h ... 23に2^(Lv - 3)を掛ける。
- バルサンを付けるかどうかは検討。付けるならL3以上にする。
- Lv上がるためには、上記の時間+上記の時間回分書き込み数が必要。例：ID/PASSでのLv3 -> 4上がるためには、23時間+23回の書き込みが必要。
