## セルフレビュー

- スレ削除は非公開化のみとし、本文・投稿者ログ・旧形式ログを保持。
- レス削除時はレス番号・スレタイトルを保持。
- 移動先keyの上書きを拒否し、移動途中の障害は同じ移動先への再実行で復旧。
- 投稿と停止・削除・編集をスレのDurable Objectで直列化。
- スレ削除・移動後は旧R2ログや旧DOから公開データが復活しないように対応。
- 削除・移動済みスレを公開の過去ログ一覧・headlineから除外。
- レス編集後は古いRange/If-Modified-Sinceによるキャッシュを使わずdat全文を返す。
- 管理ページにBasic認証・同一オリジン検証・HTMLエスケープ・no-storeを追加。
