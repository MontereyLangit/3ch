# 04. dat 落ちを採用しない

2026-09-25 決定。

## 1. 一般的な 2ch 型掲示板の dat 落ち

- 一定の基準（板ごとに異なる）を満たしたスレッドは「dat 落ち」する。
- dat 落ちしたスレッドは過去ログ倉庫に格納され（2ch では過去ログディレクトリへ移動）、書き込めなくなる。

## 2. 3ch の方針

**dat 落ちは採用しない。スレッドはスレ一覧から消えるだけで、書き込めば再び一覧に浮上する。**

- v3（末期を除く）と v5 も dat 落ちを採用していない。v6 もこれを引き継ぐ。
- v6 のスレライフサイクル設計（`../v6/docs/feature/thread_lifecycle_basic_design.md`「従来のdat落ち方式の廃止」）も同じ結論で、
  「dat 落ち」「過去ログ化」に当たる状態を持たない。本書はその理由と v5 の実動作を補足する。

### 理由

1. **dat 落ちは、ファイルベースの制約に対する措置だった。**
   dat をファイルで管理していた頃、ディレクトリがスレッドであふれるのを防ぐためのもので、
   2ch 初期に手動で倉庫へ移していた作業を自動化したもの。
   - 3ch の `.cgi` 形式の v3、Cloudflare Workers 上の v5 / v6 には、この制約がない。
   - v4 は dat 形式に近いので制約があり、dat 落ちがあった。v3 も末期は dat 落ちを採用していた。
2. **低頻度で長期間使われるスレが落ちてしまう。**
   2ch / 5ch の専門板で支障が出ていた。過疎気味の 3ch では、より顕著になる。
   方針企画書の「専門板＝定着装置」「専門板は生えるもの」とも合わない。

### スレ一覧から消す仕組みは必要

- 一覧が長すぎると、専ブラの動作が遅くなる。性能が足りずに落ちる専ブラも出てくる。
- そのため、一覧に載せる件数には上限を設ける。上限を超えたスレは一覧から外すが、スレ自体は生きている（dat は取得でき、書き込める）。

## 3. v5 の実装（確認済み）

v5 はすでにこの方針どおりに動いている。

| 項目 | v5 の挙動 | 箇所 |
| :-- | :-- | :-- |
| 一覧の上限 | `BBS_MAX_MENU_THREAD`（既定 700）件、かつ 512 KB を超えた分を末尾から外す | `board.js:88-101` |
| 一覧から外れたスレの dat | Thread DO に残り、そのまま取得できる | `thread.js` `getDat()` |
| 一覧から外れたスレへの書き込み | 書き込める。一覧に項目がなければ先頭に追加する（**sage でも先頭に浮上する**） | `board.js:67-86` |
| 書き込めなくなる条件 | 1000 レス到達・スレスト・削除・移転のみ。dat 落ちによる書き込み停止はない | `thread.js:164-168` |

- 一覧から外れたスレのタイトルは、書き込み時に dat の 1 行目から取り直す（`bbs.cgi.js:520`）。

## 4. 仕様検討への含意

- **Step 5 の DB 設計**: 一覧に載っているかどうかと、スレが生きているかどうかを分けて持つ。
  「dat 落ち」「過去ログ化」に当たる状態は作らない。
- **一覧の上限**: 板ごとの設定（`BBS_MAX_MENU_THREAD` 相当）として残す。**既定値は 3000 件程度を候補とする**
  （2ch.sc の dat 落ち基準に相当。2026-09-25 ユーザー案）。
  - 3000 件の subject.txt は Shift_JIS で 200 KB 前後で、現在の専ブラなら扱える量。
  - **Step 4 までは 700 のまま**にする。v5 の Board DO は KV 型ストレージで、1 値の上限が 128 KiB。
    subject 一覧を 1 値で持っているため、日本語タイトルだと 1,000〜1,200 件程度で上限に当たる（KB-28）。
    3000 件にできるのは、Step 5 でストレージを作り直してから（SQLite 型 DO なら 1 行 2 MB、またはスレごとの行で持つ）。
- **sage で浮上する挙動**: 一覧から外れたスレに sage で書き込むと先頭に出る（v5 の実動作）。
  一覧内のスレは sage では浮上しないので、挙動が非対称になっている。v6 でもこのままにするか、
  「一覧の末尾に戻す」などにするかを決める。
- **過去ログ（`kako`）の位置づけ**: dat 落ちがないので、過去ログ倉庫は「書き込めなくなったスレの置き場」ではない。
  v5 の過去ログ目次（`{bbs}/thread/subject.txt` など）は、スレ一覧から外れたスレを探すための索引として扱う。
- **ストレージの最適化**: 書き換わらない静的ファイルとして R2 / CDN に置けるのは、書き込めなくなったスレ（1000 レス到達・スレスト）に限られる。
