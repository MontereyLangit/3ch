# 全板共通スレ（924 / 900 スレ）

2026-11-01。利用者指示により、全板のスレ一覧の先頭に載る共通スレを実装。
v5 以来「スレキーが 924 / 900 始まりの投稿は板 `924` へ送る」という振り分けだけがあったが、
作成手段と書き込み制限がなかったため、次の規則で補った。純粋な規則は `GlobalThread`
（`bbs/.../domain/posting/GlobalThread.scala`）に置き、ハンドラはそれを呼ぶだけとする。

## 種別

| 種別 | スレキー先頭3桁 | 立てられる人 | 書き込める人 |
| --- | --- | --- | --- |
| 924 スレ | `924` | ★（キャップ）のみ | ★のみ |
| 900 スレ | `900` | ★のみ | 誰でも |

★は `processCap` が KV `CAP` で認証した通常キャップ・強キャップの両方。名前欄に `★` と書いただけでは★にならない
（名前欄の `★` は `☆` に置き換えられる）。

## 立て方

通常のスレ立て（`subject` あり・`key` なし）で、本文の先頭に `!924` または `!900` と書く。
命令と直後の空白・改行（`<br>`）は本文から取り除く。`!9240` のように数字が続く場合は命令として扱わず、通常のスレ立てになる。
命令を除いた本文が空なら「本文がありません！」で拒否する。★以外が命令を使うと
「全板共通スレッド(!924 / !900)は★(キャップ)のみ立てられます。」で拒否し、datは作らない。

スレキーはスレ立て時刻（unixtime 10桁）の先頭3桁を `924` / `900` に置き換えたもの（例 `1761990000` → `9241990000`）。
`!newthread` との併用も可（`!newthread` の処理後に残った本文の先頭を見る）。

## 保存先と板 924

共通スレは、どの板から立てても板 `924` に保存する。`readForm` が `bbs` を `924` に書き換えるため、以後の処理は板 924 への
スレ立てと同じになる。

- Thread DO 名は `924/<key>`、スレ一覧は Board DO `924` の `subjectList`。
- 板設定は R2 `924/SETTING.TXT`（無ければ既定値）。`BBS_MAX_MENU_THREAD` など一覧の上限も板 924 の設定。
- ID のグループは板 924（`BBS_ID_GROUP` 未設定時）。900 スレへの書き込みの ID は投稿元の板ではなく板 924 で計算する。
- 過去ログ目次 R2 `924/thread/<先頭4桁>/subject.txt`、`headline.txt` の板名も `924` になる。
  `bbsmenu.html` を headline から生成している場合、板 `924` が板一覧に現れる。
- スレ立て規制（`docs/thread-creation-regulation.md`）は★が対象外なので共通スレには掛からない。
- 管理画面（`/admin/*`）で共通スレを扱うときは板名に `924` を指定する。

## 全板への表示

`GET /{bbs}/subject.txt` は、板 `924` の一覧と `{bbs}` の一覧を取り、`GlobalThread.mergeSubject` で結合する。

1. 924 スレ（板 924 の一覧での並び順のまま）
2. 900 スレ（同上）
3. `{bbs}` 固有のスレ（従来どおり）

`{bbs}` の一覧に 924 / 900 始まりの行があっても重複を避けるため除く。板 `924` 自身の `subject.txt` も 1・2 の順に並べ替える。
結合は配信時に行うため Board DO の保存形式は変えない。各板の行数は `BBS_MAX_MENU_THREAD` に共通スレの数を加えたものになる。

`GET /{bbs}/dat/{key}.dat` は、キーが 924 / 900 始まりなら `{bbs}` によらず Thread DO `924/<key>` を読む。
`/test/read.cgi/{bbs}/{key}/` は 3chiko.html が `/{bbs}/dat/{key}.dat` を読むので変更不要。
書き込みは従来どおり `readForm` の振り分けで板 924 へ送る。

## 書き込み制限

`processCap` の直後（`checkGlobalThread`）で、スレキーが 924 / 900 始まりなら次を確かめる。

- スレ立て（`subject` あり）で★でなければ拒否。
- 924 スレで★でなければ「このスレッドは★(キャップ)のみ書き込めます。」で拒否。

判定は `GlobalThread.canPost`。以後の板設定・スレ設定・規制・サイズ検証は通常どおり行う。

## 変更していないもの

dat の5フィールド構造、Shift_JIS 出力、ID・トリップ・キャップの計算、DO / R2 / KV のキーと形式。
`subject.txt` の `Last-Modified` は従来どおり現在時刻（KB-06）。

## テスト

- `domain/posting/GlobalThreadSuite`: 種別判定・命令の読み取り・キー生成・書き込み可否・一覧の結合。
- `handler/PostingHandlerSuite` 11b: ★による作成、★以外の拒否、924 / 900 スレへの書き込み、他板URLからの書き込み。
- `handler/PublicRoutesSuite` 2b: `subject.txt` の結合順、他板URLからの dat 取得。
